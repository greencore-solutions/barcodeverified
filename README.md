# barcodeverified

> What the words Barcode verified mean, who may use them, and the countries whose profiles are published.

Built and run by [wefetch](https://wefetch.ai/). This is the public connect kit, MIT. It holds no deploy code and no keys.

## Connect

This surface publishes for agents; it has no tool endpoint of its own.

- For agents: https://barcodeverified.org/llms.txt
- Agent card: `https://barcodeverified.org/.well-known/agent-card.json` (copy in this repo, `agent-card.json`)
- Site: https://barcodeverified.org/

```bash
curl https://barcodeverified.org/llms.txt
```
